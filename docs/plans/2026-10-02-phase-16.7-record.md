## 2. The first design, abandoned

The first design forced a yield after begin, on branch `feat/16.7-rc-contract@5847d1d`; its record is `docs/plans/2026-10-02-phase-16.7-record.md` on that branch. Its reviews measured three failures of any fix that moves the handler's continuation:

- `Task.Yield()` captures the render thread's context, so app code that blocks the render thread on a host call deadlocks: `BackNoticeTest` hung for 30 minutes.
- `ConfigureAwait(ConfigureAwaitOptions.ForceYielding)` finishes the bridge on the pool and races the handler's own `await`: the inline facts went red in 7 of 15 runs.
- A page whose `OnInitializedAsync` awaits an inline-answered call no longer renders synchronously, so `Mount<T>` throws.

This phase therefore classifies the fault and leaves scheduling unchanged.

### A cancelled handler, Task 5 fix round 1

The ruling was: a cancellation after a begun call becomes rc 0, before any begun call it stays rc 2. The test-first run did not produce the expected red. Both probes, `begin-then-cancel` and `cancel-only`, returned rc 0 on the unchanged code, so the premise that a cancellation is rc 2 today is false. Mutation to find out why: the `new TaskCanceledException` arm in `DispatchSyncPart` was made to throw, and `cancel-only` still returned rc 0, so that arm is not reached through Blazor, whose error handling completes a cancelled handler Task first. The code arm is therefore unchanged apart from its comment, and both facts pin rc 0 with nothing sent. The mutation was reverted. This rests on the run above, not on reading Blazor's source.

Anchor proof, fix round 2: each cancellation fact asserts a probe-side `ReachedThrow` flag set just before the throw, and begin-then-cancel also asserts `LastHostCallOp` is Geolocation. Mutation 1, the flag line removed in both probes: both facts RED at "the handler body never reached its throw". Mutation 2, the begin call removed from begin-then-cancel: that fact RED at "the begin was not attempted, the last host-call op was -1". Each mutation was alone and reverted; the facts are green again.
