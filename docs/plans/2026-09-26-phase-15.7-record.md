## Row 37: provenance trace and the retirement decision

- `NativeRenderer.StyleAttributes` (`NativeRenderer.cs:1650`) is
  `new(YogaStyleAttributes.Concat(VisualStyleAttributes))`, so it is defined as the union.
- `YogaStyleAttributes` and `VisualStyleAttributes` (`NativeRenderer.cs:1639-1645`) are
  `new(BnWireVocabulary.YogaStyles)` and `new(BnWireVocabulary.VisualStyles)`.
- `BnWireVocabulary.g.cs` is emitted by `tools/BlazorNative.WireGen` from `src/wire-vocabulary.json`.
- The manifest is therefore the root of every candidate side. No independent copy of the style
  names exists in .NET.
- The generated-against-source comparison is already pinned twice, both in
  `WireVocabularyCodegenTests`: a byte-comparison of the emitted `.g.cs` against the manifest's
  output, and `TheRenderersStyleSets_AreTheManifests`, which asserts both `NativeRenderer` halves
  equal the manifest's lists. Re-pointing row 37 at the manifest would duplicate the second of
  these, which reads the same two sides.
- `ShellStyleTableDriftTests`' header records the same reasoning from #255: "a test asserting that
  two generated files agree would assert only that the generator is deterministic."

**Decision: retire.** This is the sanctioned retirement, with the NavigationTests 7.6 precedent
cited in the comment, the commit body and the `ci.yml` history line. The failure the retired fact's
message described — a style in neither half — cannot be written, because a name can enter
`StyleAttributes` only through a half.
