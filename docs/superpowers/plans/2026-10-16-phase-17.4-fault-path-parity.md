# Phase 17.4 — Fault-path parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android Release logcat carries no app text, as iOS's logs never do (#426). The slow-handler warning names the app's handler behind every forwarding control (#435).

**Architecture:**
- **#426.** `BnShellLog` becomes the single privacy seam for the Android shell. A `REDACTED` default writes `<private>` unless the app is debuggable. The stderr pump and a new `src/main` diagnostics sink route through it. A .NET drift pin holds both shells' rules together.
- **#435.** An `internal` hook in `BlazorNative.Core`, `IForwardsUiEvent`, lets each Bn wrapper hand the renderer the app's delegate, read through `[UnsafeAccessor]`. `HandlerCallSite.Resolve` consults the hook. A binder delegate falls back to the parent page.

**Tech Stack:** C# xUnit; Kotlin JVM tests (`testDebugUnitTest`, through CI); Android instrumented tests on the emulator lane.

**Spec:** `docs/superpowers/specs/2026-10-16-phase-17.4-design.md`

## Review Focus

- **A `SAFE` mark on text that is not constant**, such as a route, a node id or an app message: it leaks in Release. The drift pin's literal rule catches `$`, and the final review reads every `SAFE`.
- **A debug build that hides text:** the reveal switch set after the pump, or never set on a recreated Activity. Task 5's device test runs in a debuggable build and must see the message.
- **A wrapper whose app callback is empty**, `HasDelegate` false: the hook must return null and the key must fall back exactly as today. Task 3's control fact.
- **`@bind-Value` with `:after`** gives the binder delegate. It must key by the parent page, not by `BnInput`. Task 3's bind facts.
- **A `System.err` write the conversion misses** in `src/main`: it reaches logcat unredacted. The drift pin's `src/main` scan.
