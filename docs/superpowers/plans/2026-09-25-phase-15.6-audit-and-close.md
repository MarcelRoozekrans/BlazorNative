# Phase 15.6 — Audit and close Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Audit Milestone 15 against its Definition of Done, using evidence measured now on `main`. File the carried debt as issues. Close M15 if the audit passes.

**Architecture:** This phase writes no code. The controller files the issues and dispatches the device lanes. One implementer measures every DoD item and writes the audit report, with a command beside every number. A reviewer then re-measures a sample of those numbers.

**Tech Stack:** `gh`, `git`, `dotnet test`, Gradle (JDK 21), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-25-phase-15.6-design.md`

## Global Constraints

- **Measure at the point of writing.** No number or claim may be copied from a phase report, a ROADMAP block or an earlier audit. Every number in the report has the command that reproduces it next to it.
- **The M15 range** is `76728c9..origin/main`. Release-please version commits in that range are listed and excluded **by name**.
- **Device lanes count only on `main`'s exact HEAD.** Compare each run's `headSha` with HEAD; a green run on an older commit does not count.
- **Where a DoD item is only narrowly met, say so** rather than ticking it silently. This is the M14 precedent.
- **No tag.** `CONVENTIONS.md` records `Milestone completion tags a release: no`.
- **Commits:**
  - `type(15.6): subject`;
  - no nested parentheses in bodies;
  - no session URL;
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - no dates after the day of writing.
- **The owner's no-workarounds rule applies.** A DoD item that is NOT MET is reported as NOT MET. It is never reworded until it passes.
