# Phase 16.5 — Audit and close Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Audit Milestone 16 against its Definition of Done, using evidence measured now on `main`. Close M16 if the audit passes.

**Architecture:** This phase writes no code. The controller files the S1-margin issue if one is missing, and dispatches the device lanes. One implementer measures every DoD item and writes the audit report, with a command beside every number. A reviewer then re-measures a sample of those numbers.

**Tech Stack:** `gh`, `git`, `dotnet test`, Gradle (JDK 21), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-01-phase-16.5-design.md`

## Global Constraints

- **Measure at the point of writing.** No number or claim may be copied from a phase record, a ROADMAP outcome block, STATE.md or memory. Every number in the report has the command that reproduces it next to it.
- **The M16 range** is `3757d0e..origin/main`, where `3757d0e` is #421, the milestone start. Release-please version commits in that range are listed and excluded **by name**.
- **Device lanes count only on `main`'s exact HEAD.** Compare each run's `headSha` with HEAD; a green run on an older commit does not count. Run one dispatch at a time per workflow and ref. `ios.yml` cancels in-progress runs on the same ref. Never background a dispatch loop with `&`.
- **One rerun at most, and only for a diagnosed cause.** A lane failure is diagnosed from its JUnit XML or log first. Rerun once only for proven infrastructure or #444's signature (`BnNotificationsTests` show test never completes Granted). Record both attempts. A #444 hit makes "All tests passing" **MET NARROWLY**, citing #444.
- **Where a DoD item is only narrowly met, say so** rather than ticking it silently. This applies explicitly to #425 and #440; see Task 4.
- **No tag.** `CONVENTIONS.md` records `Milestone completion tags a release: no`.
- **Commits:**
  - `type(16.5): subject`;
  - no nested parentheses in bodies;
  - no session URL;
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - no closing keywords for the carried issues, which stay open.
- **The owner's no-workarounds rule applies.** A DoD item that is NOT MET is reported as NOT MET. It is never reworded until it passes.
