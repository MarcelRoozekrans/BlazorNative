# Phase 15.1 — Close the Nine Gaps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the nine gap facts the census found, so every pin can demonstrate its **detector** still detects — not merely that its **walk** still walks.

**Architecture:** One lesson applied nine times. Every uncontrolled detector here is an **absence assertion** — *no X survives* — and the fix for an absence assertion is **a fixed point it must still hit**. Four worked examples already exist in the tree; six of the nine are borrowable.

**Tech Stack:** C# / xUnit.

**Spec:** [`docs/superpowers/specs/2026-09-23-phase-15.1-design.md`](../specs/2026-09-23-phase-15.1-design.md)
**Census:** [`docs/plans/2026-09-22-phase-15.0-census.md`](../../plans/2026-09-22-phase-15.0-census.md) — §4.1 names all nine.
**Standard:** [`docs/pin-standard.md`](../../pin-standard.md)

## Global Constraints

- **`tests/**` and `docs/**` only.** No production source change. If something appears to need `src/`, stop and escalate.
- **Every fixed point must be mutation-proven against its own subject.** Reword the pattern past what it matches; the fixed point must red. **A positive control never observed failing is worse than none, because it reads as coverage** — that is Rule 3's own requirement, and it is this phase's entire point.
- **Run mutations ONE AT A TIME, reverting between.** `Assert` stops at the first failure, so a batched run proves one mutation while still going red — indistinguishable from success. That cost a previous phase a review round.
- **Borrow the SHAPE, not the code.** Seven near-identical fixes invite copy-paste, and copies are this milestone's subject. If a helper genuinely wants extracting, extract it **once** — Rule 8.
- **Existing suites must keep their counts** except where this plan says otherwise. These are *added* assertions, not changed subjects. A pin whose suite changes shape has been altered rather than controlled — that is a finding, not a tidy-up.
- **Update the census as each gap closes, in the same commit.** It is this phase's own record and 15.6 audits against it.
- Conventional commits, scope `15.1`. **No nested parentheses in any body** — release-please silently drops the whole commit when a `(` appears inside a parenthesised group. No `claude.ai/code/session_*` URLs.
- **Run every command in the FOREGROUND.** Backgrounding a `dotnet test` hangs a subagent indefinitely.

.NET SDK 10.0.400. If `dotnet test` wedges: `Stop-Process -Name testhost,MSBuild -Force`, then `dotnet build-server shutdown`. Suite is **1112** at branch start.

    public void TheNameExtractor_CollectsArmLabelsOnly_NotEveryQuotedString()
    {
        // …assert the parsed set EXCLUDES each non-arm string measured in step 1

Use the names **you measured**, not the census's list.
