# Phase 15.8 — Re-audit and close Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-audit Milestone 15 against its Definition of Done on evidence measured now on `main`, and close the milestone if it passes.

**Architecture:** No code changes. The controller dispatches the device lanes and runs the local tests from a clean rebuild. One implementer measures every DoD item from scratch and writes a new re-audit report, with a command beside every number. A reviewer then re-measures that report and runs mutations of their own.

**Tech Stack:** `gh`, `git`, `dotnet test`, Gradle (JDK 21), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-26-phase-15.8-design.md` (method: `docs/superpowers/specs/2026-09-25-phase-15.6-design.md`)

## Global Constraints

- **Measure from scratch at the point of writing.** Nothing may be copied from the FAIL audit, 15.7's records or ROADMAP blocks without re-measuring it. Put the reproducing command beside every number.
- **Range:** `76728c9..origin/main`. Exclude release-please commits by name.
- **Device lanes count only on `main`'s exact HEAD.** Compare `headSha`.
- **Local tests start from a clean rebuild** (`dotnet build --no-incremental`).
- **Verdicts:**
  - Use MET, MET NARROWLY with the reason, or NOT MET.
  - A NOT MET is reported, never reworded; the owner's no-workarounds rule applies.
- **No closing keywords.** Write "to be closed", never `close #N`, `fix #N` or `resolve #N`, in any PR body or commit.
- **Commits:** `type(15.8): subject`. No nested parentheses in bodies, no session URL. End each commit with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **No tag.**

### Task 4: Review, PR, close

- [ ] **Step 1: Review.** A reviewer:
  - re-measures at least six of the report's numbers with its own commands;
  - checks every verdict against its evidence;
  - spot-reads at least five files the 15.7 sweep classed as not pins;
  - runs at least three mutations of their own on M15 pins, reverting each one.

  A MET verdict whose evidence does not hold is Critical.
- [ ] **Step 2: Fix and PR.**
  - Fix any findings in one round.
  - The controller files any new findings as issues.
  - Push, and open a PR with the verdict and no closing keywords.
- [ ] **Step 3: After merge (controller).**
  - Run `complete-phase` for 15.8.
  - If the verdict is PASS or PASS WITH FINDINGS, then run `complete-milestone`. This sets the milestone to `complete` in ROADMAP.md and MILESTONE.md with **no tag**, in its own PR.
  - If the verdict is FAIL, report the gaps to the owner.
