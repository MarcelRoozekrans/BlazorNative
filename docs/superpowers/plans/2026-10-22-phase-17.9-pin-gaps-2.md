# Phase 17.9 — Pin-standard gaps, second pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record an RS1-valid red for each of #557's 13 assertion sites, and correct the overclaiming register cells.

**Architecture:**
- Two red-recording tasks: one runs locally on .NET, the other on the Android device lane.
- A docs task fixes the register and builds the git-derived coverage section.
- No product code changes.

**Tech Stack:** C#/xUnit, Kotlin Android instrumented tests, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-22-phase-17.9-design.md`

## Global Constraints

- **The red standard is RS1** (17.7 record §4 "Rulings").
  - Every row carries the exact diff, the anchor entered, the command or run id with `headSha` and attempt, and the quoted red.
  - A fixture or seam red needs its clause-3 argument.
- **The record** is `docs/plans/2026-10-22-phase-17.9-record.md`.
- **Mutations:**
  - Each runs in a detached worktree under the session scratchpad.
  - `git status --short` must be empty before each mutation and after each restore.
  - Kill stubs with a `ps -eo pid,args | grep '[h]old-stdout'` pattern. Never use `pkill -f`.
- **Device runs:**
  - Use `scratch/17.9-<id>` refs, one run at a time.
  - Wait in the foreground with `gh run watch --exit-status`. Never use `&`.
  - Check `headSha` and that the run is attempt 1.
  - Read results from the JUnit XML.
  - Delete each ref after its run completes.
- **Reworks:** a rework only strengthens a pin. It is committed as `test(17.9): …` and is followed by a full .NET suite run.
- **Commits:**
  - `docs(17.9):` or `test(17.9):`.
  - No nested parentheses, no session URL.
  - No closing keywords, except the final PR body's deliberate `Closes #557`.
  - End with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Parse-check every commit.

## Review Focus

- **Wrong-line reds:** a red that fails a line other than its site. The reviewer checks the quoted line.
- **Thin clause-3 arguments:** a clause-3 argument that names nothing tried.
- **Copied coverage:** a coverage section copied from #557 instead of derived from git.
- **`:552` wording:** the cell claims more than the renamed-executor run showed.
