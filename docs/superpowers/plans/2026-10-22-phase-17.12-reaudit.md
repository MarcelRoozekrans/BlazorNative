# Phase 17.12 — Re-audit and close Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-audit M17 against the written grading rule, and close it with no tag if it passes.

**Architecture:** No code. The work is split four ways:
- A subagent re-derives item 11 from git under the written rule and re-runs a sample of reds.
- An implementer writes the report.
- A fresh reviewer re-measures a sample.
- The PR's lanes supply item 2.

**Tech Stack:** `gh`, `git`, `dotnet test`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-22-phase-17.12-design.md`

## Global Constraints

- **Grading rule.** Item 11 is graded against `docs/pin-standard.md` "Grading a pin: sites and reds", and nothing broader.
- **Evidence.** Every number has its command beside it. Records are cited only as where a mutation is recorded.
- **Lanes.** Use the PR's lanes at attempt 1, with `headSha` compared. The #551 and #564 rules apply.
- **Scope.** No tag and no code changes. Mutations run only in detached worktrees.
- **Commits:**
  - prefix `docs(17.12):`;
  - no nested parentheses, no session URL, no closing keywords anywhere;
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - parse-check every message.

## Review Focus

- **Unit creep.** A finding that only a broader unit than the section's would count. Such findings belong in #562, not here.
- **Stale reds.** A stale red counted as fresh.
- **Red sample.** The red sample is copied from the record instead of re-run.
- **Flakes.** A flake hit graded MET.
