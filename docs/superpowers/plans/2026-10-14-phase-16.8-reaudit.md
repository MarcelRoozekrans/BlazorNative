# Phase 16.8 — Re-audit and close Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-audit all ten M16 DoD items on evidence measured now on `origin/main`, and close M16 if every item is MET, or MET NARROWLY with its reason.

**Architecture:** This phase writes no code. The controller measures the tests on HEAD: local .NET runs, the CI run, and both device lanes. It also re-reds any 16.6 pin whose code moved after its red. One implementer writes the report. A reviewer re-measures a sample of it.

**Tech Stack:** `gh`, `git`, `dotnet test` with `pwsh` on PATH, GitHub Actions. The host is Debian 13 x64, so the JVM lane runs on CI only (#491).

**Spec:** `docs/superpowers/specs/2026-10-14-phase-16.8-design.md`

## Global Constraints

- **Measure at the point of writing.** Nothing is copied from a phase record, ROADMAP, STATE.md, memory or **the 16.5 audit**. Every number in the report has the command that reproduces it beside it. The 16.5 audit is cited for its method and its findings, never as evidence.
- **The M16 range** is `3757d0e..origin/main`, where `3757d0e` is #421. Release-please commits are excluded **by name**.
- **Device lanes** count only on `main`'s exact HEAD, compared by `headSha`, at attempt 1.
  - Dispatch one at a time per workflow and ref, and never background a loop with `&`.
  - Diagnose a failure from its JUnit XML or log before anything else.
  - Allow one rerun, only for proven infrastructure, #444's signature (`BnNotificationsTests` show never completes Granted), or #453's (the biometrics boot test exceeds its 30 s wait). Record both attempts. A #444 or #453 hit makes item 2 **MET NARROWLY**.
- **Grading:**
  - **#464 against item 7:** MET NARROWLY if it contradicts the wording. It never blocks the close.
  - **#454 against item 2:** MET NARROWLY only if a local run hangs. Otherwise item 2 is MET, with the host caveat stated.
  - **Item 10:** no red on current code is **NOT MET**. A named partial is MET NARROWLY; an unnamed partial is NOT MET.
  - **Item 9** is graded on its wording; 16.7's rc change is recorded there and is not an ABI change.
- **No tag.** `CONVENTIONS.md` records `Milestone completion tags a release: no`.
- **No product code changes.** A mutation is restored, and `git status` is clean before the next one. A defect found is filed with file:line, not fixed.
- **Commits:**
  - `docs(16.8): subject`;
  - no nested parentheses in bodies;
  - no session URL;
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - no closing keywords: every carried issue stays open.

## Review Focus

- **A stale claim copied forward.** The report must not repeat a 16.5 sentence as evidence. The reviewer diffs suspicious passages against the 16.5 audit.
- **A green lane that predates HEAD.** Every lane cell carries its `headSha`.
- **A 16.6 red whose subject moved.** Task 3's per-pin `git diff --stat` table is in the report.
- **A pin 16.7 added that no record reds.** Task 4's item 10 lists 16.7's pins by name against the 16.7 record's rows.
- **The register range.** It is re-measured from `docs/pin-standard.md`, not taken from 16.5's `NR>=396 && NR<=498`.
