# Phase 16.3 — Starvation, measured Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure what a slow synchronous handler costs, add a once-per-handler slow-handler warning, publish the app-author threading page, and close #9.

**Architecture:**
- **Timing.** The render thread times each dispatch's synchronous part, using the 16.1 `DispatchScope` open and close points, plus the host-event arms. It logs a single `BnLog.Warn` per handler per session when the time exceeds an internal budget.
- **Evidence.** A throwaway harness measures the cost, and its numbers go in a phase record.
- **Docs.** A new guides page states the threading contract.

**Tech Stack:** .NET 10, xUnit, BnLog, Docusaurus (the `website/` folder), and the existing docs guards.

**Spec:** `docs/superpowers/specs/2026-09-27-phase-16.3-design.md`

## Global Constraints

- **Budget and logging:**
  - `SlowHandlerBudget` is `internal const`, 100 ms by default. The measurement may move it, but the reason must be recorded.
  - The warning never includes the payload.
  - It is sent once per handler id (or event name, for host-event arms) per session.
- **No ABI change.**
- **No change to BnLog's public surface.**
- **Tests:**
  - Pins follow `docs/pin-standard.md` Rules 2–5 and 7, in production mode.
  - Record the mutations, and revert each by reversing the edit, never with `git checkout`.
  - Tests must be deterministic: no assertion near the budget boundary.
- **Docs:** every code sample on the new page must pass `DocsSamplesDriftTests`, `DocsNameDriftTests` and the CI docs-samples compile.
- **Commits:**
  - Commit before long runs, and never use `--no-verify`.
  - Subjects are `type(16.3): subject`.
  - Bodies contain no nested parentheses, no URLs and no closing keywords. Write "#9 to be closed".
  - End each commit with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **No tag.**
