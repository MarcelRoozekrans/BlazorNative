- [ ] **Step 1: Rows 19 and 20, and group F. Check values, not existence.** In `DefaultStructTrapSweepTests`, extract the sweep into one helper that the fact and the control both call:

```csharp
    /// <summary>The sweep's detector. For every all-optional record struct with a meaningful
    /// default, <c>new T()</c> must equal the primary constructor called with its declared
    /// defaults — compared as VALUES, so an explicit ctor that chains to the wrong values is
    /// caught, not just a missing one.</summary>
    internal static (int Examined, List<string> Offenders) Offenders(IEnumerable<Type> types)
    {
        var offenders = new List<string>();
        int examined = 0;
        foreach (Type t in types)
        {
            ConstructorInfo? primary = PrimaryCtor(t);
            if (primary is null) continue;
            ParameterInfo[] ps = primary.GetParameters();
            if (!ps.All(p => p.HasDefaultValue) || !ps.Any(IsNonDefaultDefault)) continue;
            examined++;
            object declared = primary.Invoke(ps.Select(p => p.DefaultValue).ToArray());
            object viaNew = Activator.CreateInstance(t)!;   // what `new T()` yields
            if (!Equals(declared, viaNew))
                offenders.Add($"{t.FullName}: new() = {viaNew}, declared defaults = {declared}");
        }
        return (examined, offenders);
    }
```

  - Record structs have value equality, so `Equals` compares every field.
  - Confirm, and state in a comment, that `Activator.CreateInstance(t)` calls an explicit parameterless constructor when one exists. It does for structs in .NET Core 3.0 and later. When none exists, it zero-initialises, exactly as `new T()` does.
  - `PublicValueTypes` must include **nested** public value types: use `t.IsPublic || t.IsNestedPublic`, plus a check that the whole enclosing chain is public.
  - The fact calls `Offenders(PublicValueTypes)`. It keeps the floor, now stated as measured, and names `CaptureOptions` as its anchor.
  - The control calls `Offenders` over the fixtures:
    - `TrappedFixture` must be an offender;
    - the fixed fixture must not be;
    - a NEW fixture, `WrongValueFixture(int Value = 7)` with `public WrongValueFixture() : this(Value: 0) { }`, must be an offender. This is the case the old sweep missed.
  - Group F, `NewCaptureOptions_…`, is now implied by the sweep. Keep it as a named anchor and say so in its doc comment.
