# Phase 17.1 — Fault attribution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fault that a dispatch's own code raises belongs to that dispatch, even when its continuation runs inline inside another dispatch's synchronous part (#464). 16.7's pin partials (#494) are proven in the same files.

**Architecture:** Two condition changes in `NativeRenderer.cs`. `HandleException` keeps a fault in the window unless the flowing scope is a different dispatch scope of this renderer. `NoteShellCallBegun` marks only when the flowing scope is the thread's synchronous scope. Everything else is tests, mutations, text and the register.

**Tech Stack:** C# / .NET 10 (xUnit), Kotlin JVM tests on CI, `gh` for the lanes.

**Spec:** `docs/superpowers/specs/2026-10-14-phase-17.1-design.md`

## Global Constraints

- **Red first.** Every new fact is run red on unchanged product code before the fix, and the red message is recorded.
- **Mutations are recorded, anchors included.** Each runs alone, is reverted, and leaves `git status` clean before the next. Record: id, the file:line changed, the command, the red message.
- **Record:** `docs/plans/2026-10-14-phase-17.1-record.md`.
- **The fix ships as `fix(17.1)!: …`** with a `BREAKING CHANGE:` footer. Run every commit through `node scripts/commit-parse-check/check.js` before pushing. No nested parentheses in bodies.
- **Closing keywords:** the PR body says `Closes #464` and `Closes #494`, and nothing else does. Grep the commits before opening the PR.
- **No ABI change:** no export, struct field or wire op is added.
- **Local runs** use `dotnet test … --blame-hang --blame-hang-timeout 10m`, because of #454.
- **Device lanes** count only on the PR head: compare `headSha` and use attempt 1. Run one dispatch at a time per ref.
- **JVM mutations** need the Windows native library, so they go through a throwaway draft PR from `scratch/17.1-<id>`. Close it and delete the branch after reading the red.

## Review Focus

- **A's fault but no A notice.** In fact 1, if the late path drops the fault, B is clean and nothing is sent. The fact must assert A's notice exists, not only that B is rc 0.
- **The child-begin guard.** A child component's call, begun during B's re-render, must still mark B. If the new mark condition breaks it, the fix is wrong.
- **`Task.Run` still unmarked.** `AShellCallBegunOnAnotherThread_…` must stay green, and the flowing-only M4 mutation must red it.
- **The Done rule tests the right path.** The fault must come from A's own code, a Blazor-observed task, never a re-render, which is the window's under #500.
- **Text claims.** Every DOES NOT COVER line and contract sentence is either pinned or says it rests on reading.
