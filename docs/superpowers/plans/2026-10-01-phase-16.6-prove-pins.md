## Global Constraints

- Branch: `feat/16.6-prove-pins`. Device mutations live on `scratch/16.6-mut-<id>` refs cut from
  the feat branch HEAD. **A mutation never lands on the feat branch.**
- **One mutation per run, reverted between runs** (Rule 7's protocol). Locally, revert with
  `git checkout -- <file>` and confirm `git status` is clean before the next mutation.
- **Device evidence rules:**
  - **One run per ref at a time.** `ios.yml` uses `cancel-in-progress: true` per ref.
  - **Never background a dispatch loop with `&`** in the Bash tool.
  - **Before reading a run, check it:** `gh run view <id> --json headSha,attempt,conclusion`.
    `headSha` must equal the scratch commit, and `attempt` must be 1.
  - **Red test names come from the artifact**, never from the run's conclusion:
    - iOS: `ios-out-simulator/xcodebuild-test.log`, grep `Test Case '.*' failed`.
    - Android: the JUnit XML in `instrumented-test-results`.
- **A red in a test the mutation did not target** is recorded as off-target. #444 is a known iOS
  flake and #453 is a slow cold `LAContext`. If the off-target red hides the target, re-run.
- **Expected reds in this plan come from reading the code.** A run that disagrees is recorded as a
  surprise, and the mutation set is extended. **The cell is never weakened.**
- **Line numbers were read on `8be7dc4`.** Re-read each one before editing.
- **Commits:**
  - Conventional, scope `16.6`.
  - Trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - **No `claude.ai/code/session_*` URL** anywhere.
  - **No nested parentheses** in commit bodies (release-please drops the commit).
- **The win-x64 publish needs the VS Installer directory on PATH** for `vswhere`. Without it, Gradle
  tests a stale DLL. Check the DLL timestamp before trusting a JVM count.
- **#454:** a solution-wide local `dotnet test` can hang in `ReferenceFixtureBase`. Use `--filter`
  for every mutation run here. None of the 38 pins live in that fixture.
