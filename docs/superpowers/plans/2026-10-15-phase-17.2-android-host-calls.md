# Phase 17.2 — Android host-call contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android's biometrics and secure-storage work leaves `hostCallBegin` for one serial executor per handler, as iOS did in 16.4 (#440).

**Architecture:** Two single-thread daemon executors in `AndroidShellBridge`. `hostCallBegin` enqueues and returns. The after-auth work hops back onto the handler's executor. A throw on an executor completes `ERROR`. Test seams observe completions, gate and fault the jobs, and drain the executors.

**Tech Stack:** Kotlin, Android instrumented tests on the `android-instrumented.yml` emulator lane, `gh`.

**Spec:** `docs/superpowers/specs/2026-10-15-phase-17.2-design.md`

## Review Focus

- **Pin 1's red names the defect.** On unchanged code, the begin does not return while the gate is closed, because the work runs inline. The red must say so, not time out somewhere else.
- **Pin 5 calls `succeed()` from main.** From any other thread, the hop-removed mutation stays green.
- **The throw guard completes `ERROR` within a bound.** It never leaves a pending .NET call.
- **No KeyStore work on main.** Check every path from `onAuthenticated` and `onDenied`.
- **The template mirror** stays byte-identical.

### Task 3: The executors

- [ ] **Step 1:**
  - Add `biometricsExecutor` (`BlazorNative-Biometrics`) and `secureStorageExecutor` (`BlazorNative-SecureStorage`), both single-thread daemons, as `cameraExecutor` is.
  - In `hostCallBegin`, the two arms become `biometricsExecutor.execute { runJob(requestId, BiometricStatus.ERROR) { handleBiometrics(requestId, argsJson) } }`, and the same for secure storage with `SecureStorageStatus.ERROR`.
  - `runJob` signals `gateReachedForTest`, awaits `workGateForTest`, calls `jobFaultForTest`, runs the body, and catches `Throwable` with `onError` plus `completeHostCall(requestId, errorStatus, null)`.
  - Move the seam calls from Task 2's inline place into `runJob`.
- [ ] **Step 2:** The after-auth hop. In `secureSetAuth` and `secureGetWithAuth`, each `onAuthenticated` body is wrapped in `secureStorageExecutor.execute { … }`. Denials still complete directly, since they do no KeyStore work.
- [ ] **Step 3:** `drainForTest` submits a latch to each executor and awaits both, bounded.
- [ ] **Step 4:** Update the comments: `hostCallBegin`'s KDoc and the biometrics and secure-storage block get the begin contract, record, enqueue, return, in iOS's words.
