## Global Constraints

- **Record:** `docs/plans/2026-10-17-phase-17.7-record.md`.
  - Each red row has: the pin at file:line, the mutation as file:line plus its diff or one line, the anchor it enters, the command or run id with `headSha` and attempt, and the quoted red message.
  - Reds are taken on this branch's code. The mutation must change **subject code or a planted input**. Deleting the assertion does not count.
- **Mutation hygiene:**
  - Commit before mutating.
  - Mutate in a detached worktree under the session scratchpad, never in the feature worktree.
  - `git status --short` must be empty before each mutation and after each restore.
- **Routes:**
  - `.NET`: locally, with `export PATH=$HOME/.dotnet/tools:$PATH`.
  - Pure-Kotlin JVM: locally, with `export JAVA_HOME=$HOME/bn-tools/jdk-25 ANDROID_HOME=$HOME/bn-android`. If `verifyNativeAssets` fails, publish the bionic assets with `ANDROID_NDK_ROOT=$HOME/bn-android/ndk/26.3.11579264`.
  - JNA: a throwaway draft PR `test(17.7): scratch re-red …`, with one mutation per commit, run in turn. Read the result from `build-test`'s JVM step. Close the PR with `--delete-branch`.
  - Device: `scratch/17.7-<id>`, dispatched with `gh workflow run android-instrumented.yml --ref`. Run one at a time, and never use `&`. Wait with `gh run watch <id> --exit-status`. Check `headSha` and attempt 1, read the JUnit XML, and delete the ref after verifying the run completed.
- **Batching:** several mutations share a run only with a written non-interference argument in the record. A process-crashing mutation never shares a run.
- **A pin that won't red:** rework it to be stronger or more honest, then red it. If no honest rework exists, remove it and say why. Never weaken an assertion.
- **The two `AndroidShellBridge.kt` copies and the two `MainActivity.kt` copies** stay byte-identical where the mirror guard requires it. The reference copy is `src/BlazorNative.Jni/src/androidMain/kotlin/io/blazornative/shell/`; the template copy is `templates/BlazorNative.Templates/content/BlazorNative.App/android/src/androidMain/kotlin/io/blazornative/shell/`.
- **ABI:** no ABI change. The 80-byte struct and the 10 exports are untouched.
- **Commits:**
  - `fix(17.7):` for code, `test(17.7):` for test-only work, `docs(17.7):` for docs;
  - bodies have no nested parentheses and no session URLs;
  - each body ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - no closing keywords, except in the final PR body, where #537 and #538 are closed deliberately;
  - parse-check with `node scripts/commit-parse-check/check.js`.
