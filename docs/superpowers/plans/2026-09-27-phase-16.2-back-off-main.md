# Phase 16.2 — Back and navigation off the main thread Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** No main thread ever waits on .NET.
- .NET pushes `canGoBack` as a generated `BackState` notice, and a `BackUnhandled` notice at root.
- Android toggles an AndroidX `OnBackPressedCallback` from that back state, applied in the same main-thread batch as the frame that shows the page.
- Deep-link and notification navigation become fire-and-forget on both shells.
- `dispatchHostEventAndWait` becomes internal. This closes #346.

**Architecture:** Two new `hostCallOps`, 6 and 7, in `src/wire-vocabulary.json`, riding the `FaultNotice` delivery pattern from 16.1. There is no ABI change. The shells get arms for the new ops, Android replaces its platform back callback with AndroidX, and the tests span .NET, JVM, Android instrumented and XCTest.

**Tech Stack:** .NET 10 with xUnit, Kotlin with AndroidX Activity, JUnit 5 under JDK 21 and AndroidX Test (instrumented, API 34 AVD), Swift with XCTest, `tools/BlazorNative.WireGen`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-27-phase-16.2-design.md`

## Global Constraints

- **No ABI change.** The ABI stays at 10 exports and an 80-byte struct. `BlazorNativeRuntimeC.h` may change only in comments.
- **Op ids are frozen.** 0–5 as today; `BackState` = 6 and `BackUnhandled` = 7. Add them only through the manifest and WireGen, never by hand.
- **Every notice pin runs in production mode** (`StrictErrors = false`), with a strict control where it adds value.
- **Flip, never delete or skip.** Pins follow `docs/pin-standard.md` Rules 2–5 and 7, with recorded mutations. Revert a mutation by reversing the edit, never with `git checkout`.
- **Template mirrors.** Every changed shell or Gradle file that has a template copy gets the same change. `TemplateDriftTests` must stay green, including `TemplateMainActivity_EqualsTheRepos_ModuloTheFallbackAndTheImport`.
- **Commit before every long test run.** Uncommitted edits were reverted on disk during 16.1. Implementers commit in the main checkout; reviewers work in a separate `git worktree`.
- **Local JVM runs:**
  - Put `/c/Program Files (x86)/Microsoft Visual Studio/Installer` on PATH, then publish win-x64. Check the exit code is 0 and the DLL is fresh.
  - Run `gradlew --no-daemon testDebugUnitTest --rerun` with `JAVA_HOME` set to the Adoptium JDK 21. Pass `-PciSoDir` if `verifyNativeAssets` needs it; see #424.
- **Swift and instrumented tests cannot run on this Windows machine.** They are verified on the iOS and android-instrumented CI lanes, which the controller dispatches.
- **Commits:**
  - Subjects are `type(16.2): subject`.
  - Bodies contain no nested parentheses, no URLs and no closing keywords. Write "#346", never "fixes #346".
  - End each commit with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **No tag.**
