# Phase 17.11 — Pin-standard gaps, third pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write the site unit and RS1 into the pin standard, record an RS1 red for each of #561's 28 sites, and correct the overclaiming cells.

**Architecture:** One docs task writes the rule. Three red-recording tasks follow, one per route: .NET, JNA, and device. A last docs task fixes the cells and builds the coverage. There are no product code changes.

**Tech Stack:** C#/xUnit, Kotlin JUnit/JNA, Android instrumented tests, and GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-22-phase-17.11-design.md`

## Global Constraints

- **The red standard and the site unit** are the design's §1. After Task 2, they are the new `docs/pin-standard.md` section.
- **Own-assertion rule.** A red counts for a site only if that site's assertion fails, with its own message.
- **Record.** The record is `docs/plans/2026-10-22-phase-17.11-record.md`. Every row gives:
  - the exact diff;
  - the site entered;
  - the command, or the run id with `headSha` and attempt;
  - the quoted red.
- **Mutations.** Run them only in detached worktrees, with `git status --short` empty before and after.
- **Device runs.** Use `scratch/17.11-<id>`. Run one at a time, and wait with `gh run watch --exit-status` in the foreground. Delete each ref after its run completes.
- **JNA.** Use one throwaway draft PR with the JVM step narrowed. Close it with `--delete-branch`, then verify the branch is gone.
- **Stubs.** Kill them with `ps -eo pid,args | grep '[h]old-stdout' | awk '{print $1}' | xargs -r kill`. Never use `pkill -f`.
- **Commits:**
  - prefix `docs(17.11):` or `test(17.11):`;
  - no nested parentheses;
  - no session URL;
  - no closing keywords, except the final PR body's deliberate `Closes #561`;
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - parse-check before committing.

## Review Focus

- A red that fails through an earlier line, a crash, or an NPE.
- A two-line anchor red where both handlers stop, not just the second.
- The new standard section claiming a different unit from the owner's ruling.
- A cell still citing M5 or M4.
- Coverage copied from #561 instead of re-derived.
