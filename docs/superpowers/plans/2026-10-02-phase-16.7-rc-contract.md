# Phase 16.7 — Make the rc contract true (#455) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When the shell completes a host call or a fetch inside `hostCallBegin` or `fetchBegin`,
the handler's await still yields. A fault after that await then arrives as a FaultNotice, never
as rc 2. The rc contract is identical in its three copies, and a pin keeps it so.

**Architecture:** `NativeShellBridge` gets one `if (tcs.Task.IsCompleted) await Task.Yield();`
in the host-call path and one in the fetch path, so an inline completion no longer lets the
await skip its yield. Under the render thread the continuation is posted back to the render
queue and follows the existing late-fault path, ending in a FaultNotice. The contract text is
rewritten between `BEGIN rc-contract` and `END rc-contract` markers in `Exports.cs`,
`BlazorNativeRuntimeC.h` and `threading.md`, and a tree-reading fact compares the three copies.

**Tech Stack:** C# / .NET 10 (xUnit), Kotlin JVM tests (JUnit 5, JNA, NativeAOT dll), GitHub
Actions device lanes, release-please.

**Spec:** [`docs/superpowers/specs/2026-10-02-phase-16.7-design.md`](../specs/2026-10-02-phase-16.7-design.md)

## Global Constraints

- **Branch:** `feat/16.7-rc-contract`. Phase 16.7 is already `[status: active]` in ROADMAP and
  MILESTONE.
- **Scope, owner decision:** only awaits on a host call or a fetch are made to yield. An await on
  a task the app already completed itself still does not yield, and the contract says so.
- **Contract text, verbatim in all three copies:**

  > rc reports the SYNCHRONOUS part of the handler: 0 = it did not fault before it first yielded
  > (it may still be running); 2 = it faulted before yielding. An await on a host call or a fetch
  > always yields, even when the shell completes the call inside `hostCallBegin` or `fetchBegin`,
  > so a fault after the first such await arrives later as a FaultNotice host-call op, never as
  > an rc. An await on a task the app already completed itself, such as `Task.CompletedTask` or a
  > cached result, does not yield: a fault after it is still in the synchronous part, rc 2. Frames
  > from the synchronous part are delivered before the export returns; frames from a continuation
  > are delivered later, from the render thread.

      // ── 16.7 (#455): a call the shell completes INSIDE begin still yields ─────
      //
      // Since 16.7 NativeShellBridge yields after begin when the call already completed, so
      // the handler's await always suspends and a fault after it is a FaultNotice, never the
      // dispatch's rc. Each fact anchors that the fake really completed the call inside begin
      // (Rule 2). The Task.CompletedTask control pins the contract's own exception: an await
      // on a task the app completed itself does not yield (Rule 3).
      //
      // DOES NOT COVER: a shell that completes the call on another thread while begin is still
      // running, which is a race no fake here reproduces; an inline-completed call awaited
      // outside a dispatch, such as in OnInitializedAsync, where there is no rc to protect.

      private static (int Rc, List<RenderFrame> Frames, List<Task> Pending, Action<ulong, string, Task>? Previous)
          DispatchInline(string label, bool autoCompleteFetch = false)
      {
          var frames = new List<RenderFrame>();
          var pending = new List<Task>();
          Action<ulong, string, Task>? previous = Exports.PendingDispatchObserver;
          Exports.PendingDispatchObserver = (_, _, t) => { lock (pending) pending.Add(t); };
          NativeRenderer renderer = StartSession(strict: false, frames);
          renderer.Mount<InlineCompletionProbe>();
          int handlerId = HandlerFor(frames, "click", label);
          FakeShellHost.AutoCompleteHostCall = true;
          FakeShellHost.AutoCompleteFetch = autoCompleteFetch;
          int rc = DispatchBounded(handlerId, """{"name":"click"}""");
          return (rc, frames, pending, previous);
      }

      private static string ContractIn(string relative)
