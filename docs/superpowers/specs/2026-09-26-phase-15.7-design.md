## What scoping measured (2026-09-26, `main` @ `1f2b3a7`)

A read-only sweep read **all 93** hand-written test files that sit outside the tree-reader population and contain facts. It did not use file names, the proxy this milestone rejected. Results, recorded in full in the sweep record:

- **15 files hold pins, 40 pin facts in all.**
  - **11 conform.**
  - **29 have gaps: 21 cheap, 8 moderate, 0 large.**
- **The three most serious gaps:**
  - `LayoutSurfaceSequenceBandTests` holds a **third hand copy** of the layout surface that nothing pins. Rows 13 and 14.
  - `StyleAttributePartitionTests.StyleAttributes_AreExactlyTheUnion…` is a **tautology**. `NativeRenderer.cs:1650` defines the set it is compared against. Row 37.
  - `DefaultStructTrapSweepTests` checks that a constructor **exists**, not that it yields the declared defaults, and cannot see nested public structs. Rows 19 and 20.
- **~25 cross-language scalar facts ("half-pins")**, ambiguous group A. Each compares a C# constant against the .NET declaration only, never against the Kotlin, Swift or C copy, so it fails common-mode.
- The sweep also lists 78 files with no pins, each with its reason, and ambiguous groups B–F.

## Decisions (owner, 2026-09-26)

1. **Assess every pin, and fix everything.** Every pin fact found gets a verdict, and all 29 gaps are fixed in this phase.
2. **Half-pins are not pins.** Group A is recorded as *golden, not a pin*, with its reason: the facts never read the other copy. **One issue is filed** for a real differential ABI-constant pin that reads the Kotlin, Swift and C declarations from the tree. That is the M14 shape.

## Rulings on the other ambiguous groups (controller)

- **B — `DeepLinkVectorTests`.** Fixed points for pins that live in Kotlin and Swift. Not pins; recorded as such.
- **C — `ForwardedParameterNameTests` forward-target facts.** Counted as pins. Their narrow reach goes into a Rule 5 list: they red only when a target stops deriving.
- **D — `LayoutSurfacePinTests` per-type absence checks.** Restatements covered by row 9. Assessed together with that file.
- **E — `BnImagePolishDemoTests` fixture equalities.** These assert nothing: the sample defines them as `= BnImageDemo.X`. Each one is fixed or retired. The genuine two-literal comparison, `DeclaredWidthDp`/`HeightDp` against `BnImageDemo.Fixed*`, counts as a pin and is assessed.
- **F.** Folded into the `DefaultStructTrap` fix.

## Approach

- **Every fix applies the standard it fixes.**
  - A floor is set to a measured number, with its headroom stated.
  - A control drives the pin's **own** detector. Where the detector is inline, it is first extracted into a helper that both the fact and the control call.
  - A Rule 5 list states the reach.
- **The mutation table is a hard rule.** Every row must be able to go red. A row that is expected to stay green needs a contrast run; that is the 15.4 lesson.
- **Row 37, the tautology, becomes a comparison that can fail, or it is retired.** It is re-pointed at independent sources: the generated `BnWireVocabulary` halves on one side, the manifest on the other, with a floor. If no independent pair exists, it is retired with a written reason, following the repo's NavigationTests 7.6 precedent for retiring green tautologies. It is never kept as it is.
- **Row 13's third copy is pinned, not duplicated.** A fact holds `ItemNames`/`ContainerNames` set-equal to `ItemParameters`/`ContainerParameters`.
- **`DefaultStructTrap` checks values.** For every all-optional record struct, `new T()` must equal the primary constructor called with its declared defaults. That is compared by reflection over the default values, not by trusting the ctor's text. Nested public types come into the sweep. The control drives the sweep's own `Offenders` helper.
- **The register.** `docs/pin-standard.md`'s Rule 6 register gains a row for every non-tree pin file, with a per-rule verdict. It links the sweep record as its source. The census gets a short note pointing at the non-tree population, saying it is now measured and not assumed.
- **The small items.**
  - Close **#357**, citing `d481dae` / #377, `TheDispatchDeclarationScan_IsNotVacuous` and its per-shell floors.
  - File **15.2 residuals 3, 4 and 6**.
  - File the **ABI differential-pin** issue.
  - Floor `RouteMenuDriftTests.MenuRows_AreUniqueAndLabelled`, and give rows 1–2 their controls.
  - Correct the census's two false "#357 closed" claims, or annotate them with the date the issue was actually closed.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| A floor set without headroom | A later legitimate addition reds for the wrong reason, or a floor of 1 proves little | Set each floor to the measured value, state the headroom, and for presence floors name an anchor member |
| An extracted helper changes what the fact checks | A fix silently weakens a pin | Compare each fact before and after on the real tree, and mutation-prove the helper through both the fact and the control |
| The re-pointed row 37 compares two things generated from one source | It becomes a quieter tautology | The two sides must have independent provenance, stated in its Rule 5 list; if they don't, retire it |
| 29 fixes over 16 files | A long phase | Group the tasks by file family; each task is reviewed separately |
