**Date:** 2026-09-26
**Phase:** `15.8`
**Surface:** `Docs`
**Stage:** phase (one phase, implementation-ready)

**Milestone:** [M15 — A Standard for Pins](../../planning/MILESTONE.md)
**Base design:** [`2026-09-25-phase-15.6-design.md`](2026-09-25-phase-15.6-design.md). This spec reuses its method and lists only what differs.
**The audit it re-runs:** [`docs/plans/2026-09-25-milestone-15-audit.md`](../../plans/2026-09-25-milestone-15-audit.md) — FAIL: 7 MET, 2 NARROW, 2 NOT MET

## Goal

Re-audit Milestone 15 against its Definition of Done on evidence measured now on `main`. Close the
milestone if it passes.

## Approach

The method is 15.6's, items 1–7, applied unchanged: measure everything at the point of writing,
use the `76728c9..HEAD` range, dispatch the device lanes with `headSha` compared, count the pin
population, check each issue's closure and its commit, and give a verdict. These things differ:

1. **The re-audit is a new report,** `docs/plans/2026-09-26-milestone-15-reaudit.md`. It is not an
   edit of the FAIL audit, which stays as it is, so the failure and its correction sit side by
   side in the record. This is the owner's decision.
2. **Everything is re-measured from scratch,** including the items the first audit marked MET. The
   re-audit may quote nothing from the first audit, from 15.7's record or from any ROADMAP block
   without re-measuring it.
3. **Items 4 and 8 get the deepest check.**
   - **Item 4.** Enumerate the tree-reader population with the census key, and enumerate the
     non-tree pin files from `docs/plans/2026-09-26-phase-15.7-nontree-sweep.md` and the Rule 6
     register. Check that every pin fact has a verdict. The reviewer then spot-reads at least five
     files the sweep classed as not pins.
   - **Item 8.** Check that #357 is closed and that every record states how it closed.
4. **Local tests start from a clean rebuild** (`--no-incremental`). In 15.7 a stale incremental
   build produced a false red.
5. **Carried debt is already filed:** #395, #396, #401–#407 and #411–#414. The re-audit lists
   them. Anything **new** it finds is filed as an issue before the report cites it. No PR body or
   commit may contain a closing keyword for any issue.
6. **Verdict.** On PASS or PASS WITH FINDINGS, run `complete-milestone` with **no tag**, per
   `CONVENTIONS.md`. On FAIL, the gaps go to the owner and M15 stays open.
